## Signature Projects  

### [PawSure – Pet Insurance Cost Leakage Analytics](https://github.com/soundarrya/pawsure-pet-insurance-analytics)  
**Focus:** Insurance Claims Optimization  |  **Stack:** SQL Server · ETL · Views · SPs  
- Designed fact / dimension model for claims data (Pet, Disease, Clinic, City).  
- Built ETL workflow (Stage → Transform → Load → Reject Log).  
- Created KPI Views identifying high-cost diseases and slow approval zones.  
**Impact:** Exposed 70% of payout leakage sources → informed pricing reform.

---

### [StreamWise – OTT Recommendation Drop & Decision Fatigue Analytics](https://github.com/soundarrya/streamwise-netflix-decision-fatigue)  
**Focus:** User Behavior Analysis  |  **Stack:** SQL Server · BA Case Study · KPI Modelling  
- Modeled user watch sessions, scroll fatigue, and content drops.  
- Designed KPIs for session duration & recommendation efficiency.  
- Delivered BA narrative explaining root causes of content overload.  
**Outcome:** UX insights for simplified recommendations → higher completion rate.

---

### [SaaSGuard – SaaS Churn Early Warning Analytics](https://github.com/soundarrya/saasguard-churn-analytics)  
**Focus:** Customer Retention  |  **Stack:** SQL Server · ETL · Excel Dashboard  
- Built dimensional model (Customer, User, Date, Usage Fact).  
- Automated KPI Views → Daily Active Accounts & 30-Day Drop Rate.  
- Designed Excel dashboard for risk ranking and trend analysis.  
**Result:** Predicted churn 30 days earlier → enabled retention intervention.
